# Assessment Requirements Summary

The assessment asks for:
- Clear overview, architecture, setup, API reference, and testing instructions.
- Application code separated into API, domain, service, and infrastructure responsibilities where applicable.
- An automated test suite.
- Configuration, database migrations, and an API contract.
- A repeatable local setup workflow.
- Written decisions and assumptions.
- A record of AI prompts and work-session decisions.

This is a summary of the requirements, not a verbatim prompt transcript.
